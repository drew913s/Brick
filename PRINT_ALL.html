SPAWN CHECKLIST

  1. □ Issue exists with task details
  2. □ All dependencies are DONE
  3. □ File ownership declared (CREATES/MODIFIES/OFF LIMITS)
  4. □ No file overlap with in-progress workers
  5. □ New terminal opened, in Brick repo
  6. □ Slash command typed (e.g., /user:ant)
  7. □ Tracker updated (terminal #, time, files)

  • 🚫 Claims "done" with no working UI
  • 🚫 Same error 3x in a row
  • 🚫 30+ min silence (no update/commit)
  • 🚫 Touches files outside ownership
