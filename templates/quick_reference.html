✅ BEFORE ACCEPTING TEST-READY

  • URL I can visit exists?
  • Command I can run exists?
  • Button I can click exists?
  • I know what SUCCESS looks like?
  • I know what FAILURE looks like?

Test Flow

  1. Read access instructions
  2. Go to URL / run command
  3. Try happy path
  4. Try edge case
  5. PASS → move to done
  6. FAIL → comment, move to backlog
